# 🛒 Blinkit Sales & Performance Dashboard – Power BI Project
## 🔍 Introduction
This Power BI dashboard presents an in-depth analysis of Blinkit, India’s last-minute delivery app. The project focuses on uncovering trends in sales performance, outlet ratings, product category insights, and regional distribution to enable better decision-making for retail operations and customer engagement.

Built using a real-world dataset, the dashboard consolidates key performance metrics from across outlet locations and item types, offering a data-driven view into Blinkit's fast-paced retail environment.
